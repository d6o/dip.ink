## Private blocked-note audit (coordinator or dedicated curator)

Use a stable, read-only checkout or snapshot. Do not run this session against the private wiki.

```sh
python curator/scripts/audit-blocked-notes.py /private/read-only/wiki-snapshot > /private/audit.jsonl
```

The utility compares each `notes/.blocked/<slug>` with matching archived source pages. It reports:

- `exact_duplicate`: normalized body and exact attachment bytes/names match.
- `divergent`: body or attachments differ.
- `missing`: no matching archived source page exists.
- `ambiguous`: multiple candidate source pages or note files exist.
- `unreadable`: a file, encoding, empty body, or symlink prevents a safe comparison.

Normalization removes YAML frontmatter and the first H1, normalizes line endings, and trims trailing whitespace. It excludes only the blocked receipt from attachments. Frontmatter/title differences remain a human-review concern. Hash output is not a content dump or deletion authority. A normalized duplicate is not proof that a review-queue bullet is resolved.

The utility never moves, edits, or deletes files. Preserve its report with snapshot revision and review each proposed queue change in the dedicated curator workflow. Review bullets need their own cited evidence and resolution rationale; ambiguous contradictions stay for human review.
