# v0.1.57 operations and evaluation plan

## Scope

1. Inspect existing alert fingerprint, reminder, and recovery behavior. Correct demonstrated database/scope and cleanup faults without replacing deduplication.
2. Prevent healthcheck group drift through configuration checks and regression tests. Keep public `GROUP_ID=main`; private deployments supply their own group.
3. Make the contradiction janitor manual-only by default. Keep its code and surface failures rather than treating them as empty findings.
4. Add a versioned synthetic evaluation dataset and reproducible runner. Separate deterministic fixture checks from live retrieval and human review.
5. Add read-only zero-edge and blocked-note inspection. Distinguish missing evidence, divergence, and exact duplicates. Do not mutate queues or force reingest.
6. Audit tracked experiments, manual utilities, and templates using references and documented purpose. Archive only clearly obsolete material.

## Validation

Run applicable server tests, isolated Neo4j checks, installed-image tests without network access, curator tests, and release/manifest contracts. Build the local v0.1.57 image. Keep private questions, answers, note bodies, and credentials outside git and test logs.

## Rollout and rollback

Session A owns private evidence inspection, live configuration, publication, and deployment. Confirm the memory server, ingest job, healthcheck, and notification state use the same database/group configuration. Confirm janitor suspension before rollout. Exercise alert failure, reminder, recovery, and delivery-failure behavior with fixtures first.

Rollback uses the previous immutable image and configuration. Do not erase notification history, ingest failure state, source history, or queues as a rollback step.

## Explicit unresolved items

- The private runtime group and blocked-note classifications require Session A's read-only live checks.
- Review-queue entries require source evidence and human judgment; counts alone do not prove duplication or irrelevance.
- Confidence and source membership do not prove answer correctness. Live evaluation needs reviewed evidence and human adjudication.
- No automatic LLM judge or destructive graph maintenance is part of this release.
